QUICK START (5 MINUTES)
================================================================================

Step 1: Start the API server
  $ cd Backend
  $ npm install
  $ npm start
  Server: http://localhost:5001

Step 2: Register a user
  $ curl -X POST http://localhost:5001/auth/register \
    -H "Content-Type: application/json" \
    -d '{"email":"test@example.com"}'

Step 3: Verify OTP (check your email for code)
  $ curl -X POST http://localhost:5001/auth/verify-otp \
    -H "Content-Type: application/json" \
    -d '{"email":"test@example.com","otp":"123456"}'

Step 4: Copy the JWT token from the response

Step 5: Make authenticated request
  $ curl -X GET http://localhost:5001/profiles/me \
    -H "Authorization: Bearer YOUR_JWT_TOKEN"

✅ Done! You now have authenticated access to the API.

AUTHENTICATION FLOWS
================================================================================

FLOW 1: EMAIL + OTP
  User Input Email
    ↓
  POST /auth/register
    ↓
  OTP Sent to Email
    ↓
  User Enters OTP
    ↓
  POST /auth/verify-otp
    ↓
  JWT Token Returned
    ↓
  Use Token: Authorization: Bearer <token>

FLOW 2: GMAIL OAUTH
  User Clicks Gmail
    ↓
  POST /auth/connect-gmail
    ↓
  Verify with Google
    ↓
  JWT Token Returned
    ↓
  Use Token: Authorization: Bearer <token>

COMMON TASKS WITH CURL
================================================================================

CREATE YOUR PROFILE
  curl -X POST http://localhost:5001/profiles \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{
      "type": "Candidate",
      "skills": [{"name": "React", "proficiencyLevel": 4}],
      "bio": "Full-stack developer",
      "experience": 5
    }'

POST A JOB (Company)
  curl -X POST http://localhost:5001/post/save-post \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{
      "title": "Senior Developer",
      "description": "...",
      "skills": [{"name": "React", "level": 4}],
      "salary": {"min": 50000, "max": 80000}
    }'

FIND CANDIDATE MATCHES
  curl -X GET http://localhost:5001/matching/jobs/{jobId}/matches \
    -H "Authorization: Bearer $TOKEN"

GENERATE INTERVIEW QUESTIONS
  curl -X POST http://localhost:5001/api/generate-questions \
    -H "Content-Type: application/json" \
    -d '{
      "skills": "TypeScript, React, Node.js",
      "experience": "3 years full-stack development"
    }'

ADD NOTIFICATION
  curl -X POST http://localhost:5001/notification-system \
    -H "Content-Type: application/json" \
    -H "Authorization: Bearer $TOKEN" \
    -d '{
      "recipient": "user_id",
      "content": "New job matching your skills!",
      "url": "https://app.talentai.bid/posts/123"
    }'

API BASE URL:

  Production:     https://api.talentai.bid

AUTHENTICATION:
  Type:           Bearer Token (JWT)
  Header:         Authorization: Bearer <token>
  Validity:       24 hours
  Refresh:        Re-authenticate after expiration

RATE LIMITS:
  Public:         100 requests per minute
  Authenticated:  500 requests per minute
  Admin:          1000 requests per minute
  Headers:        X-RateLimit-* in response

CONTENT TYPE:
  Request:        application/json (POST/PUT/PATCH)
  Response:       application/json (all endpoints)
  Charset:        UTF-8

ERROR HANDLING:
  Format:         JSON with error code, message, details
  Status Codes:   200, 201, 400, 401, 403, 404, 409, 500, 503
  Timestamp:      ISO 8601 UTC format
